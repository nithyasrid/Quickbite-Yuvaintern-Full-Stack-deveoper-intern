# QuickBite Front-End Technology Stack

- **HTML5:** `index.html` is the document entry point.
- **CSS3:** `src/index.css` contains styling, responsive media queries, and theme variables.
- **JavaScript (ES6+):** Implements menu filtering, cart operations, order summary calculations, and local storage.
- **React:** Builds reusable UI components and manages state.
- **React Router:** Provides navigation between `/`, `/cart`, and `/order`.
- **Vite:** Development server and production build tool.
- **Browser localStorage:** Persists demo cart and latest order in the browser.

## Important scope note

This is a Week 2 frontend prototype. It uses sample menu data and does not connect to the planned Java Spring Boot backend or PostgreSQL database yet. Backend API development and integration are intended for later internship tasks.
